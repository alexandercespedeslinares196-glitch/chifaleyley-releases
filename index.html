Cómo instalarlo

  1. Descargue el archivo y ábralo con doble clic.
  2. Windows puede avisar de que no reconoce el programa. Pulse Más información y luego Ejecutar de todas formas.
  3. Siga el instalador. Al terminar, el sistema se abre solo.

La primera vez el sistema muestra un código de instalación. Envíeselo a su proveedor para que active la licencia de este equipo.

Después de instalar

  • No hay que volver a esta página. Las versiones nuevas se descargan solas y se instalan al cerrar el sistema.
  • El sistema arranca vacío: usted carga sus mesas, su carta y sus usuarios.
  • Sus ventas se guardan en la computadora del local y no se pierden al actualizar.

Requiere Windows 10 u 11 de 64 bits. No hace falta instalar nada más.
